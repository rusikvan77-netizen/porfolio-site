# Название
Проект по продаже ключей от игр на разные платформы
# Стек технологий
-php 8.2
-Laravel 12.x
-MariaDB
# Ссылка на сайт: 
http://portfoliosite.com.swtest.ru/



# Запуска проекта локально:
1) Клонировать репозиции
2) Выполнить 'composer install'
3) Скопировать 'env.example' в '.env'
4) Настроить подключение к базе данным
5) Выполнить 'php artisan migrate'
6) Запустить 'php artisan serve'
